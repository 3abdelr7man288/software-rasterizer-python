## Project Overview
This project rebuilds a 3D graphics rendering pipeline from scratch using Python and NumPy, bypassing APIs like OpenGL. By implementing a custom software rasterizer, it bridges theoretical linear algebra with practical computer graphics to reveal the math driving interactive environments.

---

## Project Architecture
The engine processes 3D geometry and handles vector graphics operations across two core stages:

1. **Vertex Shading & Matrix Transformations:** Employs 4D homogeneous coordinates to chain Model, World, Camera, and Perspective Projection matrices. Handles clipping, perspective division, and viewpoint mapping to project 3D coordinates onto a 2D screen coordinate plane.
2. **Rasterization & Fragment Shading:** Evaluates pixel intersections using edge functions and barycentric coordinates for depth testing and linear color interpolation. Computes surface normals and light vector dot products to calculate real-time Lambertian diffuse reflectance shading.
